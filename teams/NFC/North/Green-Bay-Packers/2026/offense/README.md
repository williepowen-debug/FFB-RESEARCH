# Green Bay Packers 2026 Offense

Green Bay's offensive module is built around continuity with Matt LaFleur and Adam Stenavich, Jordan Love's efficiency trajectory, Josh Jacobs' volume, and an unsettled but high-upside Watson/Reed/Golden/Kraft target tree. The key preseason work is usage charting, not proving the roster baseline.

## Files

- [`receiver-tight-end-hierarchy.md`](receiver-tight-end-hierarchy.md): target-tree finding for Watson, Reed, Golden, Kraft, and related depth.
- [`backfield-and-line-stability.md`](backfield-and-line-stability.md): Jacobs workload, Lloyd/Brooks roles, and offensive-line transition.
- [`hypotheses.csv`](hypotheses.csv): machine-readable offensive questions to test in preseason and Week 1.
