# Green Bay Packers 2026 Roster Changes

These files preserve the personnel transition supporting the Packers Core-tier module. Green Bay remains built around Jordan Love, Josh Jacobs, Christian Watson, Jayden Reed, Matthew Golden, Tucker Kraft, Micah Parsons, Xavier McKinney, Edgerrin Cooper, and Keisean Nixon, but the 2026 roster has meaningful changes on defense, receiver, offensive line, backup quarterback, return teams, and kicker.

## Files

- [`departures.csv`](departures.csv): material player exits and releases.
- [`veteran-additions.csv`](veteran-additions.csv): external veteran additions and trade acquisitions.
- [`retentions.csv`](retentions.csv): extensions and retained contributors.
- [`draft-class.csv`](draft-class.csv): 2026 draft selections and immediate monitoring questions.
- [`undrafted-free-agents.csv`](undrafted-free-agents.csv): post-draft rookie signings and current camp status where verified.
