# Minnesota Vikings 2026 Roster Notes

This Core-tier roster workspace records only transaction-level facts needed by the team module. Use the official Vikings roster and transaction pages for current 90-man status, and update these CSVs when a player movement changes a fantasy-relevant role.

## Files

- [`departures.csv`](departures.csv): outgoing veterans and role losses.
- [`veteran-additions.csv`](veteran-additions.csv): free-agent and trade additions.
- [`retentions.csv`](retentions.csv): retained players or contract-control moves.
- [`draft-class.csv`](draft-class.csv): 2026 draft class and immediate monitoring questions.
- [`undrafted-free-agents.csv`](undrafted-free-agents.csv): selected UDFA tracking for roster battles.
