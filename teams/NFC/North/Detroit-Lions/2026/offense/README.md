# Detroit Lions 2026 Offensive Research

Detroit's offensive module is built around two linked questions: how Drew Petzing changes a strong Goff/Gibbs/St. Brown/Williams/LaPorta ecosystem, and whether the rebuilt offensive line stabilizes quickly enough to preserve the scoring environment.

## Core Baseline

The facts are strong: Detroit hired Petzing, traded David Montgomery, extended Jahmyr Gibbs through 2030, retained its core passing-game players, added Isiah Pacheco and Tyler Conklin, and used Round 1 on tackle Blake Miller. The inference is more fragile: Petzing's Arizona history suggests run efficiency and tight-end friendliness, but Detroit's actual 2026 usage needs first-team route, carry, red-zone, and protection evidence.
