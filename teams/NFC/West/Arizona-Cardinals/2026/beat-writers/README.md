# Arizona Cardinals source-monitoring guide

This directory tracks official records, current reporters, analysts, and data sources for fantasy-relevant Cardinals injuries, practice roles, usage, scheme, and roster construction. `registry.md` is the editorial rotation; `sources.csv` normalizes identities; `endpoints.csv` records monitoring locations; and `candidates.csv` preserves both discovery passes.

Start with official records, add independent observations, then interpretation. Team employees are official voices rather than independent confirmation. Attribute individuals, follow aggregation to its origin, and do not reproduce paid text.
