# New Orleans Saints source-monitoring guide

This directory tracks the official records, reporters, analysts, and data sources used to monitor the 2026 New Orleans Saints for fantasy-relevant injuries, availability, roles, usage, scheme, and roster construction.

## Files

- `registry.md` is the editorial monitoring rotation.
- `sources.csv` normalizes source identity and function.
- `endpoints.csv` records monitoring locations.
- `candidates.csv` preserves both discovery passes and all dispositions.

Start with official records, then independent practice reporting, then interpretation. NewOrleans.Football supplies unusually deep independent reporting and film work but is subscription-funded; NOLA.com, ESPN, and WWL provide important organizationally independent checks. Team-employed work is direct-access official voice, not independent confirmation. Attribute every claim to its origin and do not reproduce paid text.
