# New Orleans Saints 2026 Roster Spine

This directory tracks roster movement that changes the fantasy and matchup baseline for the 2026 Saints module. It is not a full active roster; use the official Saints roster for current jersey and status checks.

## Files

- [departures.csv](departures.csv): notable 2025 contributors who left before the 2026 season.
- [veteran-additions.csv](veteran-additions.csv): veteran signings, re-signings, and trades affecting preseason roles.
- [retentions.csv](retentions.csv): retained core players and strategic contract signals.
- [draft-class.csv](draft-class.csv): 2026 draft class and immediate monitoring questions.
- [undrafted-free-agents.csv](undrafted-free-agents.csv): placeholder for UDFA detail once stable camp status is verified.
