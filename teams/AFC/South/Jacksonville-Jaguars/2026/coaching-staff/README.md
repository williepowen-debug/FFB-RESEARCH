# Jacksonville Jaguars 2026 Coaching Staff

Jacksonville is a continuity-plus-specialization staff. Liam Coen remains the head coach and offensive architect after a 13-4 AFC South title season. Grant Udinski and Anthony Campanile both return after head-coach interest elsewhere, while Brian Picucci joins as run game coordinator and Mathieu Araujo joins as defensive pass game coordinator.

## Authority model

Coen is the program and offensive structure authority. Udinski remains central to weekly offensive planning and Trevor Lawrence communication, but public Jaguars reporting still frames Coen as the head coach leading the overall offensive direction. Picucci's run-game role matters because Jacksonville has a new running-back hierarchy and a larger tight-end menu. Campanile remains the defensive play-caller, with Araujo added to sharpen coverage structure and secondary-pass-rush timing.
