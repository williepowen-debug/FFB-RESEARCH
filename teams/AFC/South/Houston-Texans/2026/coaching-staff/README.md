# Houston Texans 2026 Coaching Intelligence

Houston is a continuity staff at Core tier. DeMeco Ryans, Nick Caley, Matt Burke, and Frank Ross all remain in the same top-line roles, so the main fantasy task is not a scheme reset. The live question is whether Caley's second season and a rebuilt offensive line can turn 2025's late-season offensive gains into a stable Stroud environment while Burke preserves an elite defensive baseline.

## Authority model

| Area | Primary authority | Practical note |
|---|---|---|
| Team identity and game management | [DeMeco Ryans](demeco-ryans.md) | Defensive head coach with final team authority and a strong continuity mandate. |
| Offense and play calling | [Nick Caley](nick-caley.md) | Second-year coordinator with more personnel tailored to protection, tight ends, and the run game. |
| Defense and play calling | [Matt Burke](matt-burke.md) | Fourth-year coordinator for a defense that returns core stars and added front/secondary depth. |
| Special teams | Frank Ross | Covered only at Core roster/staff level unless return or kicker/punter roles become weekly relevant. |
