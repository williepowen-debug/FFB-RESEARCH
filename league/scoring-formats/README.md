# Scoring Formats

Document each supported fantasy format before attaching value judgments to players.

For each format, record:

- League or format name
- Redraft, dynasty, best ball, DFS, or player props
- Standard, half-PPR, PPR, or custom scoring
- Roster and lineup settings
- Team D/ST or IDP
- Superflex, tight-end premium, bonuses, and other modifiers
- Replacement-level assumptions
- Last updated date

Until a format is specified, label conclusions as format-neutral or state the assumed format explicitly.
